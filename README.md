# Text Adventure Game Practice

A lightweight, interactive text-based adventure game built entirely using vanilla JavaScript, HTML, and CSS. This project serves as a practical exercise in state management, DOM manipulation, and building dynamic branching narratives.

## 🚀 Live Demo

You can play the game live here: [Live Demo Link](http://jaymiyam.com/text-adventure-game-practice/)

## 🛠️ Tech Stack

- **HTML5:** Structure and semantic layout.
- **CSS3:** Custom styling, UI/UX layouts, and responsiveness.
- **JavaScript (Vanilla ES6+):** Core game logic, state management, and event handling.
